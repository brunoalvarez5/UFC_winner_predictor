# UFC_winner_predictor
machine learning and deep learning procedures to try and predict the winner from a UFC fight

The first current model is based on Machine Learning basic models, coded in R. However due to some errors on the data I got stuck on a 60% accuracy. After looking at others peoples work I found out the first 1600 instances in cronological orther have the red corner as winner, this obviously may bias the data. Nontheless, after curating the data in many ways it kept giving a 60% accuracy.
I got tired of trying and got to tangled with the variables and models so I will try to make a deep learning model that does it.
